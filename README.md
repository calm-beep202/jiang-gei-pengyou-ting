# 讲给朋友听（工作名）

> 让你把知道的事，讲给一个懂行的朋友听——**他听懂了，你就讲明白了。**

一个轻松的表达练习应用。**不打分、不打卡、不教套路。**

## 它是怎么工作的

- 你读到一篇 AI 概念的**材料**（标题有钩子，正文讲清楚，末尾点出名词）
- 有疑问？**直接问小问**——她懂行，会耐心讲给你听
- 觉得懂了？**讲一遍给她**——她会挑出你没讲清楚的地方

> 练的不是"说得漂亮"，是"**别人能不能听懂**"。
> 反馈不靠打分，靠"**她听懂了没有**"。

## 跑起来

```bash
python app/web.py          # → http://localhost:8100
```

零第三方依赖，只需要 Python 3.10+。

需要在自己电脑上放一个 `.env`：

```
HUNYUAN_API_KEY=...
HUNYUAN_BASE_URL=...
HUNYUAN_MODEL=...

TTS_SECRET_ID=...
TTS_SECRET_KEY=...
TTS_REGION=ap-guangzhou
TTS_VOICE_TYPE=501004
```

（`.env` 已被 `.gitignore` 排除，不会上传）

## 技术

腾讯混元（OpenAI 兼容接口）+ Python 标准库，**零第三方依赖**。

- `app/chat.py` — AI「小问」的人设与行为规则（**产品的心脏**）
- `app/web.py` — HTTP 服务 + SSE 流式返回
- `app/topics.json` — 材料
- `app/static/index.html` — 界面（单文件）
- `app/tts.py` — 腾讯云语音合成（手写 TC3 签名，不引 SDK）
