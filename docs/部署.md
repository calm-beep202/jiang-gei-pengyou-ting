## 部署步骤

### 1. 拉代码（⚠️ 绕开 github.com）

服务器**连不上 `github.com`**，但 `codeload.github.com` 通，所以走压缩包：

```bash
mkdir -p ~/jgpnt && cd ~/jgpnt
curl -sL https://codeload.github.com/calm-beep202/jiang-gei-pengyou-ting/tar.gz/refs/heads/main -o repo.tar.gz
tar xzf repo.tar.gz --strip-components=1 && rm repo.tar.gz
```

### 2. 配置

```bash
scp .env ubuntu@IP:~/jgpnt/.env
```

`.env` 不上仓库（`.gitignore` 已排除）。

### 3. Nginx

`/etc/nginx/sites-available/jgpnt`：

```nginx
server {
    listen 80 default_server;
    server_name _;

    # ⚠️ 必须关缓冲：对话是 SSE 流式，缓冲了前端要等整段结束才显示
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 300s;

    location / {
        proxy_pass http://127.0.0.1:8100;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

```bash
sudo ln -sf /etc/nginx/sites-available/jgpnt /etc/nginx/sites-enabled/jgpnt
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

### 4. systemd（开机自启）

`/etc/systemd/system/jgpnt.service`：

```ini
[Unit]
Description=Jiang Gei Pengyou Ting (web)
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/jgpnt
ExecStart=/usr/bin/python3 /home/ubuntu/jgpnt/app/web.py
Restart=always
RestartSec=3
Environment=PYTHONIOENCODING=utf-8
StandardOutput=append:/home/ubuntu/jgpnt/server.log
StandardError=append:/home/ubuntu/jgpnt/server.log

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now jgpnt
```

### 5. 防火墙

腾讯云轻量**默认只开 22**。控制台 → 防火墙 → 添加规则：

- TCP **80**（必开）
- TCP **443**（以后上 HTTPS 用）

## 踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| **github.com 连不上** | `git clone` 12 秒超时（试了 5 个 IP 全不通），但 `api.github.com` / `codeload.github.com` 通 | 用 codeload 下 tarball |
| **防火墙只开了 22** | 80 / 443 / 8100 从外部全不通 | 控制台加规则 |
| **SSE 被 Nginx 缓冲** | 前端要等整段回复完才显示 | `proxy_buffering off`（已验证：多个数据块连续到达） |
| **`pkill -f "app/web.py"` 会杀掉自己** | SSH 会话被一起杀掉，后续命令不执行 | 改用 `sudo fuser -k 8100/tcp` |
| **断线丢历史** | 用户关页面 → `BrokenPipeError` → 整个请求抛异常 → **跳过保存历史** | `sse()` 里吞掉 BrokenPipe，继续跑完并照常存 |
