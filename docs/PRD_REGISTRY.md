## 项目总目标

让用户把知道的事**讲给一个不懂的朋友听**——他听懂了，用户就讲明白了。

不做口才训练的结构化套路（模板、话术、金字塔），也不打分、不打卡；只做一件事：**用"对方听没听懂"来替代"评分"，让表达练习变成一件轻松、有社交感的事**。

**核心价值假设**（待试用验证）：
1. "讲给不懂的朋友听"比"对着镜头练/被打分"更让人放松
2. "他听懂了"那一刻的成就感，足以驱动用户下次再来

**衡量指标**（试用后确定口径）：
- 单次表达的对话轮数（用户说了几轮）
- 讲完后的主观感受（"我说明白了" / "还是没说清"）
- 是否愿意再讲一个话题

## 版本改动日志

### V0.1（2026-10-08 完成）
- 新增：话题卡片（3 个 AI 名词：Agent / RAG / 幻觉）
- 新增：AI「小问」人设——不懂的朋友（非考官、非客服），会追问、会猜、会复述确认、会主动接手
- 新增：对话流程（开场 → 讲 → 追问 → 听懂确认 → 鼓励再讲一遍）
- 新增：随时看原文（对话中可展开原文面板）
- 新增：本地服务 + 公网穿透（手机可测）
- 优化（当日迭代）：砍掉网页自带语音（改用手机输入法语音）、砍掉「我说完了」按钮（改为自然语言结束）——理由见 V0.1 PRD 落地差异

### V0.2（2026-10-09 完成，来自真实使用反馈）
- 人设收敛：新增三条禁令——禁 emoji/颜文字、禁网络俚语（"笑死"等）、禁吐槽抖机灵发表评论
- 收尾规则重写：用户讲完后**必须接一句联想的反问**，不许停在"我懂了"（原规则允许"说一句自己的看法"，实测直接导致吐槽）
- 内容去地域化：幻觉话题的「泰山学院宿舍」例子换成通用例子
- 修复：卡片正文 markdown 符号裸露（`**` 直接显示）
- 6 项验收标准全部实测通过，改动详见 [V0.2-对话优化.md](prd/V0.2-对话优化.md)

### V0.3（2026-10-10 设计定稿，待实现）

### V0.4（2026-10-10 起，10-11 主体完成，待用户体感验证）
- **起因**：V0.3 做完后用户实测——"机制全通，但没有粘性"，讲了 10 个她记 10 个，却**没有爽感、不想再打开**
- **核心诊断**：**这个互动里用户只出不进**。她给的是"回执"，不是东西。根因是 **V0.2 为了修"段子手"下的禁令，把她的人格一起砍了**——她只剩"追问"和"复述"，成了**确认机**
- **卡点**：用户真正想禁的是"她摆出考官姿态"，但顺手把"她有自己"也一起禁了
- **关键决策 22 条**（A1–A22，详见 [V0.4-活人感.md](prd/V0.4-活人感.md#关键决策)）。含一条**推翻初版设想的**：她**不能**犯错——她笨就断了"她的不懂反映你的表达"这个映射
- **已实现 12 项**：她脑子清楚 / 不好糊弄 / 可以真夸 / 会"用出来" / 带着记忆开口 / 面板主语换成"你教给她的" /
  记忆冲突按 A 解 / **打字机** / **递材料卡延迟（她的话吐完+4秒）** / **流式输出（SSE）** / **语音播报（腾讯云 TTS）** / **对话历史持久化**
- **实测挖出的坑**：混元瓶颈是**首字延迟 TTFT**（实测 19.2s，之后 78 字 0.6s 全到）——**流式治不了"等十几秒"**；
  TTS 音色只有 `501xxx`/`601xxx` 两段可用（其余 `PkgExhausted`）
- **本版成败的唯一判据**：用户有没有"想再打开"的欲望——前 6 条验收全过也不算数

### V0.5（2026-10-11 主体完成，待体感验证）

**一轮迭代里做了三件事**，详见 [V0.5-内容与角色.md](prd/V0.5-内容与角色.md)

- **① 内容形态**：钩子标题 + 正文给回完整答案 + 末尾点出名词；材料条加「AI 名词」标签
  - ⚠️ **走过一段弯路**：第一版做"给一半留一半"（材料不给结论），**实测当场被推翻**——
    用户："**我也不知道为什么差这么多，我还是要教小问的，我感觉挺别扭的**"
  - 论证：费曼技巧里"发现自己没懂"是**讲出来的后果**，不是材料的坑；把它做成前提，就成了"她在考我"
- **② 会话分段（甲）**：一条材料一段对话 + 左侧抽屉导航
  - `history.json` 从"一设备一对话"改成 `{cur, sessions}`；**记忆仍是全局的**（这是它能跟 V0.3 那条决策共存的原因）
- **③ 角色定位**：**她懂行**——用户："**小问是知识渊博的老师**"
  - 根因：提示词里"**她不懂**"出现 3 次，"要帮上忙"只有 1 次，**权重完全反了**
  - 同时**去掉所有"教"字（5 处）**——用户："**不要体现你教我的，之前教过我**"
  - ⚠️ **明确没做"完全对换"**：那会让跟豆包的差异表整个塌掉。保留"你讲一遍，她挑你没讲清楚的地方"
- 数据：`memory.json` / `history.json` 都备份为 `.bak` 后清空（用户要求"重新开始"）

| 内容供给未定 | 话题由谁产出（人工整理 / AI 生成 / 两者结合）。**当前 10 条为人工整理** | V0.4 |
